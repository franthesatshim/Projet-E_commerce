# Projet E-commerce — DEUS COM NOS

Projet de groupe : boutique en ligne de mode (chaussures, sacs, wax, perruques)
avec paiement à la livraison, paiement Mobile Money Shwary en RDC après activation et facture après encaissement.

| Dossier / fichier | Contenu |
|---|---|
| `deus-com-nos-php/` | **Application PHP / MySQL** — installation et documentation dans [`deus-com-nos-php/README.md`](deus-com-nos-php/README.md) |
| `Screenshots/` | Photos d'origine des produits (conservées telles quelles) |
| `docs/` | Documents d'architecture |
| `Design site.png`, `Planning_Developpement_Ecommerce_Scrum (1).pdf`, `excel E_Commerce.xlsx` | Maquette, planning Scrum, suivi |

Démarrage rapide : importer `deus-com-nos-php/schema.sql` puis `deus-com-nos-php/catalogue.sql` dans phpMyAdmin,
puis ouvrir `http://localhost/Projet-E_commerce/deus-com-nos-php/index.php`.
